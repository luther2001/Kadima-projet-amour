✨ DESCRIPTION DU PROJET
═══════════════════════════════════════════════════════════════
Un site web interactif et romantique créé pour célébrer une 
histoire d'amour unique. Le voyage se déroule en 4 étapes 
magiques, avec des animations fluides et des effets visuels 
époustouflants.

🎯 LES 4 ÉTAPES DU VOYAGE
═══════════════════════════════════════════════════════════════

1️⃣  ÉTAPE 1 : MATRIX ROSE ULTRA
    • Effet Matrix avec des caractères roses phosphorescents
    • Particules lumineuses en arrière-plan
    • Compte à rebours 3-2-1-0 avec effets de glow
    • Animation de cœur battant

2️⃣  ÉTAPE 2 : PLUIE MAGIQUE
    • Pluie de cœurs et d'étoiles avec mouvements naturels
    • Effets de rotation et de brillance
    • Messages flottants personnalisés
    • Plus de 150 particules simultanées

3️⃣  ÉTAPE 3 : LIVRE 3D INTERACTIF
    • Livre avec effet 3D réaliste
    • Pages qui tournent avec fluidité
    • Photos avec descriptions personnalisées
    • Effet de gradient et d'ambiance lumineuse
    • Vibrations tactiles (sur mobile)

4️⃣  ÉTAPE 4 : MOSAÏQUE CŒUR
    • Toutes les photos forment un grand cœur parfait
    • Animations de vol vers leurs positions
    • Tailles et rotations aléatoires
    • Message final "Je t'aime" avec date
    • Effet de vague à l'apparition

⚙️ INSTALLATION PAS À PAS
═══════════════════════════════════════════════════════════════

1️⃣  CRÉER LE DOSSIER
    └── Crée un dossier nommé "PROJET_AMOUR_COMPLET"

2️⃣  AJOUTER LES FICHIERS
    ├── Copie index.html
    ├── Copie style.css
    ├── Copie script.js
    └── Copie README.txt

3️⃣  AJOUTER LES PHOTOS
    ├── Crée un dossier "images"
    └── Mets tes 15 photos avec les bons noms

4️⃣  TESTER EN LOCAL
    └── Ouvre index.html dans ton navigateur

5️⃣  PERSONNALISER (optionnel)
    ├── Modifie les messages dans script.js (ligne ~10)
    ├── Ajuste les couleurs dans style.css (variables)
    └── Change les durées dans CONFIG (script.js)

🎨 PERSONNALISATION AVANCÉE
═══════════════════════════════════════════════════════════════

🎭 MODIFIER LES MESSAGES :
    Dans script.js, ligne ~12 :
    messages: [ "Ton message 1", "Ton message 2", ... ]

🌈 MODIFIER LES COULEURS :
    Dans style.css, ligne ~3 :
    --rose-principal: #ff69b4;
    --rose-fonce: #ff1493;

⏱️ MODIFIER LES TEMPS :
    Dans script.js, ligne ~55 :
    dureePluie: 4500,        // Durée de la pluie (ms)
    dureeEntrePages: 2200,   // Temps entre pages (ms)

⚠️ DÉPANNAGE
═══════════════════════════════════════════════════════════════

❌ Les photos ne s'affichent pas ?
   → Vérifie les noms dans script.js
   → Vérifie que le dossier s'appelle bien "images"
   → Vérifie les extensions (.jpg, .png)

❌ Le site est lent ?
   → Réduis le nombre de particules (script.js ligne ~250)
   → Compresse les photos sur TinyPNG

❌ L'animation du livre ne marche pas ?
   → Teste sur un autre navigateur
   → Désactive le mode économie d'énergie

❌ Le QR code ne fonctionne pas ?
   → Vérifie l'URL
   → Teste avec un autre lecteur de QR code
